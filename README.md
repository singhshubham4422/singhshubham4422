## About

I’m a Computer Science engineer interested in building useful applications and understanding the systems behind them. My work spans AI and LLM applications, backend engineering, file-security prototypes, and network-focused research. Recent public projects include retrieval-backed helpdesk workflows, RAG evaluation, and a Windows desktop file organizer.

## Technical skills

- **Languages:** Python, TypeScript, JavaScript, and C# in public projects; C++ and MATLAB in research work.
- **AI and LLMs:** TensorFlow, Hugging Face Transformers, Intel Extension for Transformers, PyTorch, Sentence Transformers, ChromaDB, and Gemini API. Training and project work includes fine-tuning, quantization, and CPU inference optimization.
- **Application engineering:** FastAPI, Flask, React, REST APIs, PostgreSQL, .NET, and WinForms.
- **Security and systems:** AES-256-GCM, PBKDF2, 3DES, RSA, ECC, Kafka, Spark Streaming, LSTM-based anomaly detection, and routing-protocol analysis.
- **Security tooling familiarity:** Burp Suite, Wireshark, Nmap, and OWASP ZAP; Metasploit at a basic level.

## Featured projects

### [HelpSphere AI](https://github.com/singhshubham4422/HelpSphere-AI)

An AI-assisted IT helpdesk workflow application. Its FastAPI backend contains agent routing, retrieval and vector-store modules, automation, and a ServiceNow client; the frontend uses React and TypeScript.

**Stack:** Python · FastAPI · React · TypeScript · ServiceNow API

### [Cost-Efficient RAG and LLM-as-Judge Assessment](https://github.com/singhshubham4422/synlabs-genai-assessment)

A two-part applied AI assessment: a document-grounded question-answering service using a persistent ChromaDB store and Sentence Transformers embeddings, plus an LLM evaluation pipeline with validation, bias checks, and audit logs.

**Stack:** Python · FastAPI · ChromaDB · Sentence Transformers · Gemini API

### [Agentic Workflow Engine](https://github.com/singhshubham4422/agentic-workflow-engine)

A small FastAPI backend for running Python workflow nodes over shared state, with conditional routing, loops, tool orchestration, and per-step logs. The repository includes a code-review workflow as an example.

**Stack:** Python · FastAPI

### [Neural Chatbot with Intel Extension for Transformers](https://github.com/singhshubham4422/chatbot)

A neural chatbot project built around Intel Extension for Transformers. The repository includes fine-tuning notebooks and a CPU-oriented dependency set.

**Stack:** Python · Intel Extension for Transformers · Hugging Face Transformers

### [Secure File Vault](https://github.com/singhshubham4422/SecureFileVault)

A Flask web application with a companion command-line interface for file encryption and decryption. Its code includes password-derived AES-256-GCM keys and separate 3DES, RSA, and ECC paths. This is an educational project, not a production security product.

**Stack:** Python · Flask · Cryptography · PyNaCl

### [FileManager](https://github.com/singhshubham4422/FileManager)

A .NET 10 Windows desktop organizer for scanning, previewing, categorizing, and arranging files. The project documents search filtering, collision handling, and rollback/undo for file operations.

**Stack:** C# · .NET · WinForms
